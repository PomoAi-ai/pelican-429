# 灌木与野果丛：各阶段独立定义与透视图

状态：草案（2026-10-11）。本文可独立复制；所有新增数字均为**绘图草案**，不代表游戏模型、生长、碰撞、采集或存档已经按此实现。

## 已有依据与本次草案

空间按2026-10-11新定义：格子深 2、Z=[−1,+1]，格子之外前沿[+1,+1.5]、后沿[−1.5,−1]各 0.5，墙厚0.2位于后沿[−1.2,−1]。现有经济资料中的食物系统不因本图自动进入阶段 1。所有尺寸、挂果和砍丛后状态均为本次绘图草案；普通灌木不自动视为可食野果丛。

本页的灌木是不可站的装饰植物。游戏树形里的 bush（资料名“矮冠树”）冠顶是平台、可以站立，归[树木定义](natural-tree-definitions.md)，不属于本页。

## 整丛放在人物身体区之后

![树木与灌木整株后置到人物身体区之后](/concepts/natural-plant-rear-clearance.png)

灌木与树木共用后置规则（core-coordinates.md 第 3 节）：整丛贴格子背面、放在人物身体区 [−0.3,+0.3] 之后，即 Z=[−0.9,−0.3]，不进入身体区和前沿。所有阶段固定根中心Z=−0.6，落在深2的宿主格内，不需要根土台。采果只去果，不改变位置与范围。草地不受后置规则限制，仍覆盖宿主整格顶面。

灌丛完全在格子内，与后沿的背景墙零交集，成熟包络 XY 内可以照常铺墙。室外无墙时，装饰性灌木也可放进后沿。身体区 [−0.3,+0.3] 待按角色实测复核；角色模型、动画、遮挡和碰撞尚未在运行时验收。

## 形体与占位

![灌木与盆景的冠幅、根部宿主、盆底承托透视与XZ俯视](/concepts/natural-shrub-bonsai-space.png)

根锚点 (0,0,−0.6) 固定在宿主格顶面靠后处。成熟预留宽 2×高 1.5×深 0.6，范围 X=[−1,+1]、Y=[0,1.5]、Z=[−0.9,−0.3]。枝叶、果实和残留根桩都不进入人物身体区及前方（Z>−0.3）；根部不得离开有承托的土面。组合图中根部宿主为X=[−0.5,+0.5]的一格；成熟三根枝干中心X=−0.44、0、+0.44，均落在该格内。冠宽2不等于根部占两格。

成熟未挂果、成熟挂果、采果后三个状态尺寸相同；果实贴在叶冠外表面且整体仍在冠层包络内，用果实有无区别状态，不用整丛缩小表示采果。砍丛后的 0.45×0.2×0.25 是残留根桩和低枝，不代表完整灌木仍在原处。

## 生长与采集

- 植株生长：幼丛 → 生长中 → 成熟未挂果。
- 指定可采果物种：成熟未挂果 → 成熟挂果 → 采果后；普通装饰灌木不进入果实循环。
- 采果只移除果实，保留成熟植株。再次挂果的周期与条件未定，不等同于整株重新生长。
- 砍丛移除地上大部分枝叶，留下短桩与根；之后能否再萌、再萌到哪一阶段均未定，不把砍丛后直接恢复为成熟挂果。
- 连根移除与砍丛不同：若未来启用连根移除，应删除活株和根，实体尺寸为零；本图展示的是保留根桩的砍丛结果。
- 野果种类、食用资格、采集数量、木材/枝条产物均未定，不用红色小球外观替代可食物种定义。

## 碰撞与待定项

整个冠层不是一块实心砖，不承托角色（可站的是树木里的矮冠树）。枝条或灌丛是否阻挡、XY 交互范围、通行代价待定；不能直接把宽 2 格的外观包络当作宽 2 格的墙。

若进入玩法，生长阶段与挂果/采果状态要分别保存。本轮资料采用成熟包络检查净空，根部宿主挖除则移除该株；掉落表现及物种间距待定，不能卸载区块后重新生成满果灌木。
