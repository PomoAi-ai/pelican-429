## 公告正文

### 鹈鹕 429 v0.1.0 · 首次公开试玩

**世界拒绝访问。我们继续向前。**

《鹈鹕 429》是一款正在制作中的横版动作冒险游戏。从一场 AGI 降智风暴出发，跟随鹈鹕与 Grassy，走进算力与废墟交织的世界。

浏览器打开即玩，无需下载，推荐使用电脑键盘与鼠标。

- [在线游玩](https://pelican429.pomoai.vip/)
- [进入游戏](https://pelican429.pomoai.vip/?mode=story)
- [观看序章](https://pelican429.pomoai.vip/?mode=intro&opening=finale)
- [源码与开发说明](https://github.com/PomoAi-ai/pelican-429)

这次试玩可以体验：

- **序章「AGI 降智风暴」**：四个音符把 AGI 推向 99%，一道 429 劈下。黑暗里，新的旋律重新响起。
- **主线「深入山体堡垒」**：从黑洞前哨进入多层机房，清理外围守卫，迎战 Tibo 与 Sam。
- **两种角色形态**：移动、跳跃、飞行与战斗；主线中击败 Tibo 后解锁鹈鹕与 Grassy 之间的变身。
- **自由世界与场景探索**：探索种子生成的瓦片世界，以及山体堡垒、算力大教堂和光纤深渊。

这是开发中试玩，主线剧情与关卡仍会继续完善。其他场景的自由探索不代表后续主线章节已经完成。

遇到问题或有建议，欢迎在 [GitHub Issues](https://github.com/PomoAi-ai/pelican-429/issues) 留言，附上复现步骤、浏览器与设备信息；也可以在 X 关注 [@grassy429](https://x.com/grassy429)，或通过首页二维码加入交流群。

本项目由 [PomoAI 中转站](https://www.pomoai.ai) 赞助。感谢参与制作的 AI 模型、Hyper3D Rodin，以及 three.js、Vite、TypeScript、Node.js、Blender 等开源项目。
