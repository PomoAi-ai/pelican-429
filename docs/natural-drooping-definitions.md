# 下垂植物：草裙、苔须、垂藤、垂花、悬崖盆景与垂枝树

状态：2026-10-10 植物透视资料补充。本页分别定义六种会向下垂展的形态；下垂是生长轮廓，不等于枯萎，也不把整株直立植物倒置。沿用前方为−Z、中央砖深1、前后各预留0.5的制图坐标，尚未接入游戏。

## 六种下垂透视对照

A～D横向均收在宿主宽1之内，组合图只展示外露前棱；背面下垂需要沿对应背棱、向Z正侧重建，并检查后墙净空。相邻格内部接触面不重复生长。上方宿主被挖除时，同步去掉失去支点的下垂段。

## 悬崖盆景的承托与净空

图E的台面为0.7×0.7，完整承托同为0.7×0.7的盆底；盆沿0.76×0.76可略超出台面。台体范围X、Z均为[−0.35,+0.35]，台顶Y=0。垂枝从盆口向前绕到Z<−0.35，再降到盆底以下，因此没有穿进台体。容器不缩小、不倾倒，土面仍为Y=0.45。

预留宽1、深1不变，但高2的净空按盆底以上1.2、以下0.8分配：X、Z=[−0.5,+0.5]、Y=[−0.8,+1.2]。它不能直接占用普通直立盆栽仅从盆底向上2格的预留；要检查台沿、下层平台和下方植物。将盆移到完整大台面中央时，枝条不能照旧穿入台面，需换成台沿摆放或直立形态。

## 生长与采后状态如何表达

- 草裙、苔须：先保留贴面层和短须，再向下延展；修剪只缩短外露长须，顶草和贴面苔层保持，除根才清除对应附着层。
- 垂藤：萌芽短枝 → 向下延长 → 长短错落的成熟叶帘 → 剪短后保留上沿支点。不能套用从砖底向上攀附的四阶段图作为下垂方向。
- 垂花：短叶枝 → 向下长枝 → 末端含苞 → 朝下开花 → 采花后保留枝叶；图D为成熟开花形态。再开花条件和产物仍待玩法定义。
- 悬崖盆景：幼株先在土面上生长 → 主枝越过盆沿 → 延长至盆底以下 → 修剪收短垂枝；拔除后仍是原固定尺寸空盆。搬盆保留植株状态，同时重新检查下方净空。
- 垂枝树：幼树尚未形成长帘 → 冠层展开后从冠缘长出短垂枝 → 成熟垂枝降低到Y=1.2 → 砍伐后只留树桩。普通剪枝与砍伐整树是不同结果，不能把短枝修剪画成砍树。
