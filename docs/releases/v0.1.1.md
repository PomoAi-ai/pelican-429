# 鹈鹕 429 v0.1.1

试玩：https://pelican429.pomoai.vip/

## 本次更新

- 手机视窗默认缩放为 125%，桌面默认 100%；菜单新增 75%–200% 缩放滑杆和恢复默认按钮。
- 游戏画布支持双指捏合缩放，摇杆和攻击按钮不参与缩放手势。
- 主角呆毛的跑动、起跳和下落摆动更加明显，固定发根并保持头型、脸和耳朵不变形。
- 版本号同步为 0.1.1，性能面板显示当前构建版本。

## 相比 v0.1.0 同时包含的已上线更新

- 手机自动瞄准、独立全屏与安装入口、手机 Boss 难度调整。
- 骑乘时释放技能、骑行与飞行切换，以及 Boss 变身镜头调整。
- 自由世界天气、角色头发和围巾动画改进。
- Pages 仅拉取正式版所需模型，减少构建下载量。
