## Rodin 工作顺序与返工规则

1. 发型：正、右、背三张独立图，分别显式标 Front / Right / Back；Gen-2.5 High。第一次先查是否混入头/耳、后脑厚度、辫子、发尾。
2. 身体：从用户指定的无头发基础原图准备输入，沿用原图比例与服装，不继续采用新画的连体服草稿；生成连续身体起点，最终头使用已确认 v9，不接受重生成头替换。
3. 每次返工仅针对一个主问题，保存截图、版本号、提示词、剩余次数与优缺点。保留当前最佳候选，避免盲目用完次数。
4. 不确认几何，直到正/侧/背轮廓、局部连接、对称与拆件需求通过并供用户查看。材质不能修复错误几何。
5. 下载后 Blender 核对拓扑、头壳贴合、颈接缝、膝肘环线，统一绑定；idle/walk/run/jump 接地与变形通过后才进共享游戏资源。
