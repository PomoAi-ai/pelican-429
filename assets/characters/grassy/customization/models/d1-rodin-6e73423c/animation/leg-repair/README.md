# D1 腿部绑定修复

后续曲面增强已完成，当前导出资产以 `../leg-curves/README.md` 为准；本页保留初次绑定修复记录。

## 根因
- 原模型膝部收窄与轮廓转折约在 Z=0.84，旧膝骨与权重中心为 Z=0.70。模型本身的小腿轮廓再叠加低位动画弯折，形成多次折弯观感。
- 靴筒上沿约 Z=0.47，旧脚权重过渡为 0.29–0.37，使靴口受到小腿骨驱动，出现斜折。
- 膝附近原网格是跨度较大的长面，直接蒙皮时膝窝硬折明显。

## 最终修复
- 膝中心改为 Z=0.84，与原表面转折一致；权重过渡 0.73–0.95。
- 整靴跟随脚，关节驱动点上移到靴筒内；仅裸露踝部在 Z=0.47–0.55 混合，保持鞋口完整。
- 裸腿长面线性细分，增加 4314 顶点，动画派生网格共 23943 顶点。源 refined.blend 未改。
- 原表面与 UV 映射保持；新增顶点 UV 采用线性插值，不声称拓扑或 UV 数组原样不变。
- 未降低步幅，未修改四个动作时长。

## 验证
四动作共 208 个采样帧检查通过：有限坐标、脚底不穿地、支撑脚接地、首尾闭合、小腿中段与整靴刚体误差。
旧位置范围会在小腿中段及靴筒产生非刚性变形；新增自检可检测该回归。
