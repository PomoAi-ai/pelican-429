# Sam 原始 Rodin 模型四向审查

已实际查看真实正、背、左、右四向渲染及叠图。未修改原始 `source.glb`。朝向为 Blender Z 向上、正面 -Y；自身左胸路由胸章、圆耳、短动物吻、蓝灰眼和黑尾尖均存在。

## 判定：需要小幅局部校准

实际正面下颌按像素 `(512, 487)` 人工定位，射线落在网格 `(0, -0.248272, 1.863931)`。全高 2.7，约 **3.2294 头身**，略超 3.2 上限；视觉标记约有 ±8 px 不确定性，不能把边界结果直接称为通过。头部总体已接近母版，不适合大幅重塑。

正面头部含耳宽约 529 px，参考约 510 px。侧面后脑接近参考，但鼻吻比注册参考短约 20–24 px。源模型尾巴向后伸得较远，导致侧面包围盒偏移；不能为了尾巴而压缩整个角色身体深度。

## 已提供给构建环节的修正初值

- 以发顶 Z=2.7 为锚，头部 Z ×1.01874，使下颌约到 Z=1.84826，目标 **3.17 头身**。
- 头部 X ×0.97，减少约 3% 的正面过宽；从脖子至下颌平滑应用。
- 头部 Y ×1.055 并平移 -0.0209，相当于绕后脑 Y≈0.38 轻增头深，优先补足短吻，保持后脑位置。
- 尾巴以根部 Y≈0.23 为锚，将后伸长度 ×0.87，最大 Y 从约 0.91766 降到约 0.828。只修尾巴，不缩身体/腿。
- 尾巴横向 X ×1.03；手臂适当横向展开约 2.5%，以正面轮廓为权威兼顾背面。前后原画尾巴横向范围互相略有冲突，不可能让同一个刚体尾巴精确匹配两张独立插画的所有像素。
- 这些是需再次渲染确认的构建参数初值，不能当成已通过的最终模型。
