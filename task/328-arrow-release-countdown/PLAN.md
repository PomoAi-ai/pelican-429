## Goal
瞄准箭头本身显示真实可释放等待时间，覆盖前一个技能尚未结束和同技能连续第二次拖出的冷却。
## Non-goals
不改释放缓存、连招、冷却或战斗时间轴，不将松手改为持续排队自动释放。
## Acceptance Criteria
- 倒计时沿箭头移动，保持水平、清晰可读，不能继续放在技能组上方。
- 读真实动作锁和目标技能冷却，两者并行时取较大值；计时结束恢复可释放提示。
- 吞弹反吐与光子独立技能遵循实际规则。
## Decisions
- UI 与计算查询分别实现；子代理探索真实战斗门控后实现只读逻辑和必要测试。
