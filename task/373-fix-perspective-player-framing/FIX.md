## Problem
透视场景中的玩家显示大小和转身表现与正常游戏不同。

## Root Cause
- src/app/perspective-controls.ts 的 aim 用固定 18 格高覆盖游戏镜头距离，工具栏又缩小了画布；模型实际身高相同，屏幕尺寸不同。
- src/app/room-scene-preview.ts 覆盖游戏 FOV，并以默认外观创建玩家，未读取游戏保存的搭配。
- 透视玩家直接切换朝向；正常游戏按移动和攻击状态平滑转身。

## Fix Plan
- [x] 使用游戏 FOV 和镜头距离，按可用画布高度补偿距离，保持正常视角每格的屏幕尺寸。
- [x] 复用角色外观存档与游戏转身速度、触发条件，保留观察镜头与游玩独立控制。
- [x] 保持模型实际尺寸、碰撞及无限飞行不变。
