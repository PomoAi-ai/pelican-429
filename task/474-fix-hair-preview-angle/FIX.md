## Status: done
## Task: 474
## Related: 472
## Baseline Commit: c292d188

## Problem

总览鼠标旋转后生成的详情链接包含任意浮点角度，例如 `-93.97058823529424`。详情页显示“渲染实验加载失败 / 未知观察角度”，无法查看新头发。

## Root Cause

`src/app/d1-hair-gallery.ts:61` 序列化自由旋转的真实角度；`src/app/d1-render-lab.ts:338` 却只接受六个预设角度。镜头定位本身支持任意有限角度，接收方的预设白名单错误地拒绝了正常链接。

## Fix Plan

- [x] `src/app/d1-render-lab.ts` — 角度边界只要求有限数值，不取整、不吸附到预设角度。
- 不修改模型、材质、动画和总览生成的链接。
