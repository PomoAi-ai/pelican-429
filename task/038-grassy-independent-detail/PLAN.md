## Goal

## Non-goals

## Acceptance Criteria
- 独立的 Blender 源文件、GLB、生成脚本和路径清单。
- 正背左右及斜侧视角可检查，提供脸部、服装和鞋子细节渲染。
- 重点制作脸部形体、分层发束、织物材质、褶皱缝线、手指和鞋带。
- Blender 源文件可重开、GLB 可加载且材质纹理完整。
- 完成后在当前模型页面添加新模型，显示名称为 `gpt6.1sol版本`。
- 将实际模型正面与侧面直接和母版并列比较，头发总体积、侧分走向、眼睑与脸型、服装轮廓必须优先于面数和纹理密度。
- 本轮必须对宽硬发束、偏平脸型与尖鼻、浮起领环和僵硬衣褶做明确形体改变；新旧真实渲染并列检查，文件可加载不能作为造型改善的依据。

## Constraints
仅新建 `scripts/grassy_atelier`、`assets/characters/grassy/model-atelier` 和 `public/characters/human/models-atelier` 的内容。使用 Blender 5.2.2 LTS，不修改已有模型。静态美术资产按视觉检查，不新增复述实现的自动测试。

## Decisions
- 使用独立的生成模块与独立输出目录，避免与同时进行的修改相互影响。
- 角色 Blender 坐标为 X 左右、负 Y 朝前、Z 向上，目标高度约 3.1。
- 姿势沿用参考图的自然站姿，分部件和材质保存，方便后续编辑。
- 参考图只读读取，打包进新 Blender 文件；程序不依赖旧任务的生成脚本。
- 无不可逆或外部操作，直接实现并验证。
- 根据实际渲染修正袖肩连接、法线图片写入顺序、后袋贴面和发束衔接；导出副本先求值所有修改器，再按材质合并。
- 用户否定首轮还原度，撤回首轮视觉完成结论并重开制作。首轮技术检查结果仅说明文件能正常使用，不能证明外观符合参考。
- 重塑侧分蓬松发型与不规则发束，缩小眼白并增加眼球眼睑层次，重塑小下巴与双颊，缩短露出的脖子，调整肩袖斜落、衣摆与布料堆叠，以及鞋头皮革体积。
- 使用统一灯光与相同高度的正侧面比较图，展示实际网格渲染；保留母版只读，不使用生成图片替代三维模型验收。
- 实际比较 AgX、Standard 与 Khronos PBR Neutral 后选择 Khronos，保持母版的鲜红毛衣与暖桃肤色；使用圆盘面积灯以减少瞳孔上的方块反光。
- 独立视觉审查量得鞋/卷边正面投影比例偏小；整鞋绕踝中心外旋 22°，并改善罗纹领圈和裤卷边。
- 根据原始图片像素修正刘海和后发高度；侧后发改为直接沿头骨参数曲面采样，解决 Bézier 中段陷入底帽导致的截断发根。中央后发约 2.11～2.15、耳侧约 2.22～2.26，保留自然低后颈弧形。
- 统一侧面对照后补充冠前发量、衣裤前后厚度，修正手背朝向；眼孔扩大并下移，鼻尖使用连续粗糙度纹理，避免局部材质切换产生硬亮块。
- 未新增自动测试；本次美术外观以实际多视图渲染验收。未提交或推送。
- 用户再次要求完善造型，重开美术制作。已有代码探索覆盖本轮区域，直接按模块并行设计和实现；开始前的独立模型、代码与渲染保存在临时目录中用于真实新旧比较。
- 头发允许重塑主刘海和冠部路径，按参考改饱满截面、短软交叠束和向上弯曲翘束；面部重塑按钮鼻、眼眶及耳内体积；服装改贴颈领口、局部斜褶、裤口堆褶和贴合曲面的鞋面。

- 本轮末次调整：侧后发统一分层向后下流向，发根深入底帽、晚露出以减轻断束；瞳孔缩小并恢复棕色虹膜，耳廓加入分叉内嵴；毛衣 UV 袖身边界随袖轴下移，避免切到腹部。针织与牛仔纹样取自原始参考的小块布料，去除大范围明暗后用于独立 UV 材质；未投射角色图片。
