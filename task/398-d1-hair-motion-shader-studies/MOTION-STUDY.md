# D1 动作与发丝研究

研究对象为实验页实际加载的 `public/characters/human/customization/d1-outfit-game.web-1k.glb`。本次直接解码该文件的 `EXT_meshopt_compression` 数据，用本仓库 three.js 的四元数插值及蒙皮矩阵，以 120 Hz 取样；没有修改 GLB、共享 rig、游戏动作或 V1–V6 材质效果。

## 结论与优先级

1. **头发僵硬来自资产绑定。** `Hair` 的 14,516 个导出顶点全部只有 `head = 1` 的有效骨权重；骨架没有发束骨。`Head` 的 30,778 个顶点也全部绑定 `head`。四个动作中 `neck`、`head` 的局部旋转均不变化，头发因此与头部完全刚性同步。仅调整灯光、材质或头骨旋转不能产生发梢惯性。
2. **走跑循环位置连续，但落脚速度不连续。** 首尾姿态误差约为浮点精度；左鞋中心在循环交界处的前后速度明显突变：walk 从末段 `+0.188853` 变为起始 `-0.614303` 单位/秒，run 从 `+0.309665` 变为 `-1.831597`。原制作曲线的摆动段使用 smoothstep、支撑段使用线性匀速，两段在落脚时只有位置连续。这是慢放时值得观察的脚步顿挫，不能宣称已有循环断帧或位置跳变。
3. **跳跃末尾本身正确，播放器需要明确管理结束状态。** jump 在 1.6 秒回到起始姿态；共享 rig 使用 `LoopOnce` 和 `clampWhenFinished`。旧实验页没有将“动作已经结束”显示成暂停状态，暂停按钮继续后也不负责从头重播。新增实验播放控制器在末尾显示暂停，继续或重播从零开始，保留末帧供研究。
4. **帧间穿地很小。** 烘焙帧上的接地基本正确，四元数插值的中间帧有轻微下探：walk 最低 `-0.000124`，run `-0.000577`，jump `-0.001085` 单位。角色总高约 3.1，不宜为这个量级直接修改共享骨架或加全身抬升补丁。

## 资源与骨架

所有动作均为 30 fps 烘焙，每个动作含 78 条通道，即 26 根骨骼各自的平移、旋转和缩放。恒定通道以两个 STEP 样本保存，运动通道为 LINEAR 样本。

| 动作 | 时长 | 含首尾的源采样数 | 播放契约 |
| --- | ---: | ---: | --- |
| idle | 3.2 s | 97 | 循环 |
| walk | 1.2 s | 37 | 循环 |
| run | 0.8 s | 25 | 循环 |
| jump | 1.6 s | 49 | 单次，停留末帧 |

## 独立实验实现

新增 `src/render/grassy/d1-lab-motion.ts`，只管理实验页的原有 `createD1Rig()` 实例。控制器持有当前动作和最多一个淡出动作，快速切换前清掉更早的淡出动作；避免三个以上动作在低权重下继续运行。重复选择同一动作会从零播放。

接口为 `createD1LabMotion(rig, resetMotion)`：

- 状态：`action`、`gait`、`duration`、`time`、`paused`、`speed`。
- 操作：`setSpeed(rate)`、`setGait('original' | 'smooth')`、`select(id)`、`togglePause()`、`replay()`、`seek(seconds)`、`step(1 | -1)`。
- 时间轴定位和前后逐帧立即停在目标姿态；逐帧步长固定为源动作的 `1/30` 秒，不依赖慢放倍率。
- `update(dt)` 推进共享 rig，并返回实际推进秒数；暂停返回零，jump 最后一步截断到末帧并进入暂停。
- 重播、定位、逐帧和切动作调用 `resetMotion()`，让实验页清除发梢惯性历史；应用层用返回的推进秒数同步眨眼与发丝。
- 步态默认原动作。walk/run 切换原版与候选时保持相位及暂停状态，停止旧混合并重置惯性；idle/jump 仅保存步态选择，下一次进入 walk/run 时生效。`dispose()` 停止候选动作并从 mixer 解除候选 clip。

发丝实验建议复用现有 Hair 网格，固定发根、仅在发梢增加小幅惯性形变；不能整体旋转 Hair，否则头皮与辫根会离开头部。应基于当前实例克隆后的资源或独立着色器补丁实现，不能改缓存几何或共享 rig。四根裙骨已经有动画，初版工具只观察其已有动态，避免用另一套摆动覆盖原动作。

慢放与时间轴先使问题可复现，再决定是否需要独立动作改良版。走跑脚步如果继续改善，应在独立候选 clip 中让摆动段的端点速度接上支撑段，使用 30 fps 源帧与帧间接地共同核对；本轮没有擅改这两条原始曲线。

## 独立顺滑步态候选

后续新增 `src/render/grassy/d1-lab-gait.ts`，导出 `createD1LabGaits(rig)`，返回独立的 `walk-smooth-gait`、`run-smooth-gait` 两个 AnimationClip。源 clip 与当前实例姿态在生成前后完全一致。

候选仅重建左右 `thigh`、`shin`、`foot` 的六条旋转轨道，原有其余 72 条轨道逐条克隆保留，身体起伏、手臂、裙摆和头部动作不变。使用实际 skeleton 的 inverse-bind 矩阵读取骨长和关节位置，使用实际 Shoe 网格计算鞋底高度，沿用制作脚本的前向弯膝解析 IK，没有缩放腿长或全身抬升。

支撑时间、步幅、脚掌俯仰及抬脚高度继续使用原制作参数。仅将摆动段的水平位移改为三次 Hermite，令摆动两端的速度等于相邻支撑段的匀速。设半步幅为 `s`、支撑占比为 `d`、摆动归一时间为 `v`、端点切线为 `m = 2s(1-d)/d`，则原 Blender 前后轴位移为：

`s(4v³ − 6v² + 1) + m(2v³ − 3v² + v)`。

连续目标轨迹在支撑与摆动之间实现 C1 衔接，随后以 120 Hz 重烘焙为普通四元数轨道。运行时仍使用原有 three.js 动画混合器；离散烘焙后的插值不是数学意义上完全连续的一阶导数，以下量化保留实际剩余差值。

| 接缝前后速度差绝对值（单位/秒） | 0.803168 | 0.081081 | 2.141265 | 0.183978 |
| 速度差减少 | — | 89.9% | — | 91.4% |
| 最低鞋底 Y | -0.000123569 | +0.000000000086 | -0.000577409 | +0.000000168 |

候选的左鞋接缝前后速度分别为 walk `-0.530779 → -0.611861`、run `-1.637323 → -1.821301` 单位/秒，不再在接缝前后反向。右脚在 run 的循环接缝处正处于摆动段，其有限差分差值包含正常加速度，不应将所有速度差都称作接缝缺陷。

候选帧间下探约减小 92%；腿段变化处于浮点精度范围，所有 IK 目标均可达。两条候选在本地 Node 运行中的一次生成耗时约 79 ms。`npm run typecheck` 已通过。

## Rodin 头发资产兼容与隔离

冻结的新全身包 `d1-outfit-rodin.glb` 可以加载并生成候选步态，但它还包含身体、头部和衣物的变化，因此最终实验没有直接替换整个包：

- 双鞋的顶点、法线、UV、骨权重和索引与旧 baseline 完全相同。
- Head 主体相对旧版统一缩放为 `0.9997019931345806`，拟合残差只有 `2.35e-7`。
- Outfit 的 UV 相同，但 8,242 / 22,950 个导出顶点位移超过 `1e-5`，最大三维位移 `0.04149`，骨权重和部分三角索引也改变。
- 骨节点、关节列表、动作时长和关键帧时刻相同；原全身新包的骨平移最大变化约 `0.000374`，不能称为原动作逐字节保留。

为了仅引入用户指定的新头发，最终产出 `public/characters/human/render-lab/d1-outfit-rodin-hair.web-1k.glb`（6,745,352 bytes）。以冻结的旧 baseline 为底，保留旧二进制数据的完整前缀和旧资源表，仅让 Hair 网格引用追加的新几何与专用 1K 纹理。新 Hair 的位置乘以 `1.0002980956999845`，回到旧头部的坐标尺度；10,049 个顶点全部绑定旧骨架的 head，关节索引 17、权重 1。

局部合并后实际通过 GLTFLoader / MeshoptDecoder 解码验证：

- 旧 BIN 前缀逐字节一致；所有旧节点、skins、animations、scenes 及所有非 Hair mesh 保持一致。
- 旧 accessors、bufferViews、materials、textures、images、samplers 完整保留；只追加新头发所需资源。
- 实际全高 `3.1001480783`，脚底 `0.0000001498`，满足共享 rig 的 `3.1 ± 0.02` 与脚底误差契约。
- 四条原动作保持一致；在合并后资源上重新生成的两条候选步态，其全部轨道名称、times、values 与旧 baseline 逐项完全相同，因此接地与步态测量保持不变。

原始新全身包和其独立 web-1k 压缩版保留用于对照。专用 web-1k 由现有 `build-web-models.ts` 的临时副本生成，只替换输入清单、根路径及独立报告路径，没有修改生产脚本、资源清单、生产 GLB 或总构建报告。压缩版为 6,235,244 bytes，相对原包 40,415,720 bytes 缩小 84.6%；所有非图片 buffer 已逐项验证无损。

证据：[仅换头发合并检查](evidence/rodin-hair-only-merge.json)、[新旧全身包比较](evidence/rodin-full-asset-comparison.json)、[独立 web-1k 构建报告](evidence/rodin-web-1k-build-report.json)。发型正侧面贴合和渲染效果继续由独立实验几何与浏览器人工验收完成。
