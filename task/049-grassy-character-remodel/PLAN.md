# PLAN -- Grassy 参考造型重塑

## Status: done
## Task: 049
## Related: 036-grassy-surface-refinement, 048-fix-grassy-version-label
## Baseline Commit: 无 HEAD；已保存 before-remodel 源模型、三档资源与渲染

## Goal
改善 gpt6.1astra版本的脸部神态、短碎发轮廓、柔软衣褶和材质，使其显著接近已确认的正面、右侧参考；完成实际渲染比较后更新共享游戏资源。

## Non-goals
不做动作、不改 Sonnet 资源或鹈鹕、不调整已确认的 3.10 格高度。

## Acceptance Criteria
- 深棕眼睛、柔和高光、圆润鼻尖和脸颊，避免猫眼和贴片感。
- 刘海分束长短交错，减少大片光滑叶片和头盔感；根部连接自然。
- 肩袖、领口、裤腿和手指轮廓放松，衣褶是局部弯曲，不是环状肿块。
- 针织、丹宁与鞋面有可辨材料差异，颜色与参考相近。
- 四向真实渲染与上版同角度对照，三档从同源派生，保留 gpt6.1astra版本 标签。

## Constraints
Blender 仅由主代理以已成功的授权环境启动；子代理不启动 Blender。先输出到独立工作目录，实际比较后才更新共享资源。视觉验收不以代码测试或面数代替。

## Decisions
- 沿用已探索的静态构建、GLB 导出和共享展示加载路径；复用现有架构，不另开技术设计阶段。
- 三路子代理分别对照原图设计并重塑头脸、头发和衣身；主代理处理表面、灯光与渲染迭代。每路先报告可见问题和实现方案。
- 静态范围、参考图、比例与版本名均已确认，不存在需要用户裁决的设计分歧。
- 保留旧源文件与三档资源；预览阶段不覆盖页面资源，便于直接比较。
- 根据两轮实际渲染继续修正：下颌底点回到颈内；裤腿根、袖根收进连续衣身；第三轮重写侧后发束路径与顶部截面，避免短方块与扭折黑面。
- 丹宁洗水使用顶点色叠乘打包纹理；采用本机 glTF 导出器支持的 RGBA Mix/Multiply 节点，最终读取 GLB 验证 COLOR_0。
- 实际入场验收发现目录新增另一套模型后，场景仍用单一 manifest 校验全部模型；改为从共享路径读取各自目录清单，以资源路径匹配统计，链接随选择更新。
- 用户再次否定造型，继续本任务。新一轮集中还原偏心蓬松短发、明亮棕眼与面颊、柔软衣褶、较短饱满的鞋；不把无破面或导出成功等同于好看。当前雕塑另存 before-portrait-remodel。
- 当前会话应用 Ponytail Full；继续复用建模装配和共享资源，修改限定在角色和现有展示页，不增新框架、依赖或视觉断言测试。
