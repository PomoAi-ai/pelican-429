# PLAN — 左侧统一菜单与自动能量门

## Status: done
## Task: 425
## Related: 424
## Baseline Commit: d2d72f4

## Goal
场景演示菜单移到左侧，住宅演示与网站使用一致的界面风格；能量门靠近自动开启、离开自动关闭，以能量消散/聚合呈现开合；当前场景窗户改为宽3格、高2格，并说明门旁灯的用途。

## Non-goals
不改建筑整体尺度、家具或远景；不删除灯具；不迁移或重置已有住宅存档；不提交、推送或部署。

## Acceptance Criteria
- 顶部导航保留，左目录与控制、中央演示；住宅和旧lab风格一致，窄窗口不溢出。
- 门无需E或按钮，左右两侧均自动感应且按楼层识别；在门中不会被夹住，边界不反复闪开关。
- 开关可清晰看见激光与能量消散/重组，保留面向玩家柱子的半透明效果。
- 当前演示的窗户为宽3格、高2格，背景墙开洞与窗尺寸匹配。
- 建造、游玩、天气和世界控制保持可用，旧存档可正常读取。

## Constraints
复用共享游戏资源与状态；只在门状态实际变化时更新碰撞，不逐帧重建模型或写存档。渲染与UI用浏览器验收，纯逻辑用已有测试。

## Decisions
- 窗尺寸按用户最后明确的宽3格解释为3×2，不等待可推断的澄清。
- 三个子代理分别负责UI、门逻辑与窗开洞、共享门特效；主代理负责应用集成与浏览器验证。
- 本轮前置备份在 /private/tmp/residence-auto-door-start/，避免把历史未提交工作误算为本轮差异。
- 探索与设计合并：已有共享目录、门renderer和门碰撞安全判定完整，无需新架构；三个子代理按各自现有链路直接设计实现，无待决审批项。
- 左栏使用网站深青灰与浅绿高亮；住宅demo控件/状态条统一，saved保持原布局与配色。
- 门按人物包围盒到门板的间距1.5格内打开、2.25格外关闭，仅垂直交叠门洞响应；复用既有防夹逻辑。
- 旧glazing占位2×2不能直接扩大，否则贴墙的已有存档加载失败；新增3×2景观窗资源用于当前示例，旧资源仍保留供旧布局使用。
- 门边小蓝灯是壁灯；门外高柱为能源设备柱，地面短柱为庭院短灯。本轮只说明用途，不擅自删除。
- 共享门开门0.4秒、关门0.75秒；按用户最终偏好，以膜碎解/光粒散出与反向聚合为主，白芯扫描为辅，移除滑动缩放和拖尾。门膜、蜂巢与前侧发光层共用连续消散进度，保留实体门框和毛玻璃柱。
- 中途反向保持当前开度，粒子沿原路径回聚；动作结束保留短暂余辉，重复setOpen不重启动画。
