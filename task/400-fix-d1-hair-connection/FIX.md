## Problem
用户反馈头发仍未处理好，重点是正面、侧面以及与头部的结合。保留所有既有版本，继续在独立渲染实验中修正。

## Root Cause
`src/render/grassy/d1-lab-hair-fit.ts` 的补束使用单个三角面内的 UV，新增侧束没有原有头发的纹理层次，形状过于规整；仅压回内侧发根不足以改善可见悬浮感。实测刘海整片与额头存在较大间隙；此前侧窗覆盖率测的是耳前侧脸，并非耳朵，不能作为填满目标。

## Fix Plan
- [x] 新增 `rodin-contour` / 自然收拢版，原始 Rodin 和上一补束贴合版保持可选，旧源码与检查点逐字节一致。
- [x] 新候选仅形变原发束，保留 UV、索引、蒙皮；刘海整束向额头收回，耳侧发壳沿厚度内收，让现有耳廓露出。耳前发梢轻微缩短。
- [x] 切换发型保留配色、取景和预设角度；自由鼠标旋转不写入 URL。
- [x] 浏览器检查正面、45°、两侧、背面、闭眼、跑步、跳跃及 V7/V8/V9，截图保存在 evidence。

## Decisions
- 冻结头部和原始头部的耳区几何一致，未修改头部；原问题来自发壳遮耳。
- 不采用局部向后拉发壳的方案，其纹理与形状拉伸明显；最终使用沿厚度的平滑内收。
- 耳后的内发壳允许埋入头皮和耳廓内部，由原头部表面遮住，不宣称所有几何完全不相交。
- 保留全部历史渲染版本，不调整游戏或共享材质；当前为新增视觉候选，最终审美选择仍由用户决定。
