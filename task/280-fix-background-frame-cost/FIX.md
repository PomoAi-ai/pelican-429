## Problem
用户要求背景整合后尽量不卡，减少首次显示与每帧渲染的额外开销。

## Root Cause
- free-world-background.ts：堡垒四层图片只依赖镜头，但可见时每帧都重新合成到RenderTarget。
- 背景预取只下载/转码；纹理首次进入真实绘制时才触发GPU上传，多个主题资源可能集中在首次显示的帧上传。

## Fix Plan
- [x] 根据镜头世界矩阵、投影矩阵和目标尺寸复用堡垒合成结果，移动/缩放/窗口改变时重绘。
- [x] 在资源预取和室内加载阶段初始化GPU纹理，保持原图片清晰度、区域渐变与失败行为。
- [x] 只改背景渲染/纹理加载；不新增依赖、性能开关或渲染细节单元测试。
