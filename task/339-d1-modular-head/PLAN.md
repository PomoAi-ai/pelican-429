# PLAN -- D1 独立头部、发型与曲面质量

## Status: blocked
## Task: 339
## Related: 337, 338
## Baseline Commit: 975f136

## Goal
重建与七视图更接近的脸部三维曲面，重建独立可替换的头发；裸腿采用实际曲面平滑，保留修复后的关节和四个动作。

## Non-goals
不制作新服装或新动作，不新增发型商城/全套捏人界面，不使用外部付费生成，不提交推送。

## Acceptance Criteria
- 鼻唇颏和下颌的实际曲面修复，立体睫毛；正侧45度近景检查。独立眼球候选没有通过视觉验收，当前保留源虹膜贴图，不计为完成独立眼球重建。
- 独立头发文件与命名分组、独立材质，偏分发束贴近参考，支持后续替换挂接。
- 真正曲面细分/平滑的腿形，不改变细腿和靴子尺寸，不恢复多段异常弯折。
- 新资产接入现有共享展示和动作模块，旧资产保留。

## Decisions
- 采用 dev 与局部曲面重建流程；已完成头部偏差探索（338），不重复探索整个工程。
- 现有模型的头部只有平滑着色，无 Subdivision；腿部只有线性细分。将独立重建几何而非用曝光和法线掩饰。
- 脸头、发型、腿部分别并行制作；统一坐标：Z-up、前方-Y，全高3.1，头骨z2.18–3.00，最大半宽.415，后脑y+.365；发顶3.10。
- 主代理负责模块装配和共享加载适配，保留旧完整模型可回退。
- 浏览器实看淘汰了程序生成的完整脸头/板状发型：眼形、眉眼距与发束层次偏离参考。最终改为保留原脸眼UV和原发束，实际曲面细分、局部鼻唇修正、独立睫毛及补齐头皮；程序候选仅保留为研究记录。
- 原头/发材质分区存在颈饰误分类与开口；使用共享选面函数保护衣领，原发型只保留主连通片，小洞补面并加内衬发帽。
- 多视图与外观校准用于记录实际偏差，数值自检不替代浏览器美术验收，不宣称已完全复刻参考。
- 头发外侧发梢收窄约5.70%；眉区域平滑只处理内部点，保持与头发相接的边界，消除侧面透空。
- 裸头浏览器验收发现源脸壳与头皮支撑衔接仍有明显折边。源脸壳有460条开放边、4处切口。规则裁切与受约束平滑候选虽然封闭主头壳，但正侧45度仍有额头凸沿、颞部折带和耳根片状连接，未通过必需视觉验收，停止继续派生，正式场景保留戴当前发型的稳定版本。
