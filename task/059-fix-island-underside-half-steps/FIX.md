## Problem
- 空岛底部：贴岩苔垫、攀附叶丛、下垂枝簇观感差；灰色低多边形岩板水平外伸，苔垫像悬空的绿色饼片，垂枝是宽叶带。
- 半格：半格与整格相接处是 0.5 格高的硬直台阶，整格侧壁上半段像被直接切开，草皮在台阶处断开；单块半格像一块方砖。
- 方向（用户确认）：空岛底部整体收敛重做；半格整体重做，只改渲染，不改碰撞与世界生成。

## Root Cause
- `src/render/sky-island-view.ts:136` `islandLumpGeometry` 用转面法线 + 灰褐配色、`planSkyIslandParts` 给岩块很小的 sy 与较大的 sx，岩块成为水平灰板；`createRootParts`（:29）苔垫是 sx 1.5 / sy .32 的扁椭球，垂枝用宽叶带 `addStrand`，与岛体泥土脱节。
- `src/render/surface-smooth.ts:80` `nextCell` 只连接顶边高度相等的相邻格，半格（顶 .5）与整格/斜坡之间 0.5 的高差成为链端，平滑地表在此断开。
- `src/render/tile-view.ts:481` 半格两侧对空气时按小圆角处理，整格朝半格一侧因邻格是实心而按内部边处理，侧壁上半段不圆角、不浮雕、无草边，形成硬切面。
