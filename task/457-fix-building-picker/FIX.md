## Problem
资源面板缺少搜索、卡片与说明占位过大、滚动区域固定高度；切换自然材质严重卡顿。

## Root Cause
src/ui/resource-picker.ts — 每帧连续生成三张模型缩略图，队列结束销毁渲染器，切换材质重新生成同一组形状。
src/render/building-material.ts — 每次实例化重复生成完整自然纹理，实测每次约 116–149 ms。
src/ui/resource-picker.css — 固定 440px 列表高度，形状卡片堆叠长文案。

## Fix Plan

- [x] 缓存自然纹理数据、复用缩略图渲染器和中性形状预览，拆分生成工作。
- [x] 搭建侧栏按可用高度分配滚动区域，精简说明。
