# PLAN -- D1 原画配色对比

## Status: done
## Task: 397
## Related: 396
## Baseline Commit: d2d72f4

## Goal
在独立渲染实验中新增原画配色，用同一视角和动作直接比较；优化肤色、发色、蓝白衣服与金边，尽量接近用户最初截图右侧原画。按用户追加要求，各阶段版本全部保留，当前提供六种效果，可随时选择任意两版比较，最终由用户选择。

## Non-goals
不改变当前游戏、原展示场、模型或贴图资源；不提交推送，不扩展到重建模型。

## Acceptance Criteria
- 柔光原版与原画配色可并排或单独查看，镜头、动作、眨眼与灯光同步。
- 新版按现有原画参考校色，页面展示参考，原版仍可查看。
- V1 柔光原版与用户要求保留时的 V2 原画初调固定保留；V3 柔润原画、V4 立体绘本、V5 清晰赛璐璐、V6 柔彩哑光分别保留。
- 左右版本可选择并保存在网址中，刷新仍显示所选组合。
- 检查正面、45°、全身、近景和闭眼，确认无渲染错误。
- 类型检查、现有测试与构建通过。

## Constraints
- 复用上一任务共享模型和连续眨眼；渲染UI不新增自动测试。
- 工作区其他改动保持原样。

## Decisions
- 复用上轮已完整探索的加载、材质和生命周期路径，不重新探索全仓。
- 一份角色与场景分两次绘制，切换校色uniform，避免两套角色动作或眨眼出现不同步。
- 沿用dev流程，本地可回退调整没有需暂停审批的条件。
- 用户已明确参考为右侧角色原画，并允许实现自定义 GPU 渲染；采用现有 WebGL 的自定义材质着色程序，无需新增依赖。
- V2 修改前的四个源文件归档于 checkpoints/v2-source.tar.gz，画面记录 evidence/v2-retained.png；后续校色只进入新的版本分支。
- V3 消除肤色阈值造成的斑驳并压低高光，V4 使用更明显的冷暖明暗层次；版本共用资源与动画。
- V3/V4 继续推进前另存 checkpoints/v3-v4-source.tar.gz。V5 增加分层阴影和稍强描边，V6 采用低饱和衣料与无描边，两者只新增高版本分支。
- 用户尚未选择最终版本，不替换正式游戏，也不自动淘汰已有版本。
