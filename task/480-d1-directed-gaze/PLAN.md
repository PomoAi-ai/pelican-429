# PLAN -- 球眼方向控制与鼠标跟随

## Status: completed
## Task: 480
## Related: 439, 479
## Baseline Commit: c292d188

## Goal

让当前 39 号预览直接使用可转动球眼，直观控制注视方向并支持跟随画面中的鼠标；改善机械平行转眼和大角度眼白过多的表现。

## Non-goals

不继续调整耳朵或头发，不改正式游戏默认眼睛，不重制现有球眼 GLB。

## Acceptance Criteria

- 当前无 eyes 参数的 39 链接能显示球眼与方向控制；保留原眼片对照。
- 支持点选方向、手动水平/垂直角度、鼠标跟随和自然扫视，模式互斥。
- 所有渲染卡片共享眼球姿态；拖动继续控制相机，鼠标跟随不误触旋转。
- 虹膜保留在球面；共同目标驱动两眼，保留美术眼窝校准；闭眼和低头视线正常。
- 鼠标退出、切模式、暂停动作后手动注视仍可控，事件随页面清理。

## Decisions

- 按当前眼睛对话把“视角方向”理解为眼球注视方向；不更改已有镜头控制。
- 沿用已有球眼资产、head 绑定、setEyeGaze 和渲染共享模块。
- 先前只读探索已覆盖球眼结构、接口与兼容入口，本轮复用；同会话子代理只负责共享球眼姿态/虹膜改进，主任务负责预览 UI 和接入。
- 39 的 Head 已与 31 同源，允许球眼接入；39 无显式 eyes 参数时默认球眼，其余版本保持原默认。
- 当前闭合 morph 只支持下视轻收睑；上视不强行拉扯现有眼睑。
- 低风险可回退的代码与 UI 改动，无设计审批停止条件。UI/渲染人工验收，不新增 DOM/CSS/three 实现细节测试。

## Final Decisions / Results

- 九宫格按正面画面的左右标识，和鼠标水平输入一致；旋转镜头后保持头部局部方向。
- 直接以球体 +Z 指向目标会覆盖作者眼窝的外斜校准，浏览器出现明显内斜；最终改为共同目标相对中立目标的方向增量作用到原 rest。正视严格保持作者姿态，不宣称虹膜轴严格物理交于同一点。
- 虹膜半宽由 .50 调到 .57，减少眼白过多；手动水平范围±18°、垂直±12°，下视借用闭合 morph 轻微收睑。
- 实际 GLB 数值自检通过：中立严格 rest，四向/四对角增量符号正确、姿态有限、100%闭合不变。
- 浏览器验收通过：39省略eyes默认球眼；31显式sphere仍正常；左右/上下、角度边界、暂停时方向控制、鼠标两向跟随、退出归中、拖动镜头、自然扫视切换、45°半闭和全闭；切patch隐藏方向控制，切01自动恢复patch；全部11种渲染同步视线。控制台无warn/error。
- npm run typecheck 通过；npm test 1962/1962通过、301 suites、0 fail/skip；npm run build 通过，仅既有chunk体积提示。最后眼窝校准修正后重跑typecheck/build和实际GLB数值自检，不重复全量test。
- 聚焦审查与 git diff --check 通过。未添加实现细节测试。未改耳朵、头发资产或正式游戏的默认眼睛，未提交推送。
- 截图证据保留在本地制作目录，未随代码提交。
- 当前限制：鼠标是画面位置到头部局部角度的映射，未做侧视下空间物体追踪；现有闭合morph不支持上视时单独抬上眼睑。
