# 下垂植物：草裙、苔须、垂藤、垂花、悬崖盆景与垂枝树

状态：草案（2026-10-10）。植物透视资料补充。本页分别定义六种会向下垂展的形态；下垂是生长轮廓，不等于枯萎，也不把整株直立植物倒置。沿用前方为+Z（core-coordinates.md）；深度按2026-10-11新定义：格子深2、Z=[−1,+1]，前沿、后沿在格子之外各0.5，尚未接入游戏。

## 悬崖盆景的承托与净空

图E的台面为0.7×0.7，完整承托同为0.7×0.7的盆底；盆沿0.76×0.76可略超出台面。台体范围X、Z均为[−0.35,+0.35]，台顶Y=0。垂枝从盆口向前绕到Z>+0.35，再降到盆底以下，因此没有穿进台体。容器不缩小、不倾倒，土面仍为Y=0.45。

预留宽1、深1不变，但高2的净空按盆底以上1.2、以下0.8分配：X、Z=[−0.5,+0.5]、Y=[−0.8,+1.2]。它不能直接占用普通直立盆栽仅从盆底向上2格的预留；要检查台沿、下层平台和下方植物。将盆移到完整大台面中央时，枝条不能照旧穿入台面，需换成台沿摆放或直立形态。

树木和灌木贴格子背面布置，整株在Z=[−1,−0.3]，位于人物身体区[−0.3,+0.3]之后（core-coordinates.md 第 3 节，待实测）；树冠和垂枝同样不能越过Z=−0.3。草、苔和沿边藤不套用此退让。树根固定Z=−0.65，各阶段不前后移动。冠内连接枝与垂枝连续相接；挂点按真实网格连接，不把解析球面上的浮空点当作树枝根部。枝叶按真实深度遮挡，砖体和树干不会错误盖住更靠近镜头的叶片。

## 生长与采后状态如何表达

- 草裙、苔须：先保留贴面层和短须，再向下延展；修剪只缩短外露长须，顶草和贴面苔层保持，除根才清除对应附着层。
- 垂藤：萌芽短枝 → 向下延长 → 长短错落的成熟叶帘 → 剪短后保留上沿支点。不能套用从砖底向上攀附的四阶段图作为下垂方向。
- 垂花：短叶枝 → 向下长枝 → 末端含苞 → 朝下开花 → 采花后保留枝叶；图D为成熟开花形态。再开花条件和产物仍待玩法定义。
- 悬崖盆景：幼株先在土面上生长 → 主枝越过盆沿 → 延长至盆底以下 → 修剪收短垂枝；拔除后仍是原固定尺寸空盆。搬盆保留植株状态，同时重新检查下方净空。
- 垂枝树：幼树尚未形成长帘 → 冠层展开后从冠缘长出短垂枝 → 成熟垂枝降低到Y=1.2 → 砍伐后只留树桩。普通剪枝与砍伐整树是不同结果，不能把短枝修剪画成砍树。

本页给出六种成熟下垂形态及21个变体状态透视：垂藤4、垂花6、悬崖盆景5、垂枝树6；与基础植物的33个状态分别列示。新增变体的尺寸由实际图形逐状态计算，动画与生长时间仍待玩法定义。图示垂枝不形成实心墙，也不自动提供攀爬或平台碰撞。

## 宿主与人物通道

- 只允许生长在真实外露的砖底、悬岩底、洞顶。两块实心砖之间的内部接触面不生成植物；下方已有实心块的局部底面不能作为附着点。
- 生长、放置与修剪都检查完整枝叶包络及下方净空；最长垂叶不能伸进人物需要通过的空间或下层平台。低矮通道改用短须或不放置，不能靠取消碰撞来掩盖遮挡。
- 支撑砖被移除时，其底面附着根、枝叶与花一起移除，不保留悬空植株。相邻砖仍有独立支点的植株保持原位。
- 底面植物不套用树木和灌木的前侧0.25格预留规则；它们按实际悬垂包络、洞顶高度及人物通道检查。底面苔须与顶面草分别占用不同附着面，不影响顶草铺满格子。

本节额外补充三种底面成熟形态及四个底面悬垂藤叶状态，不计入上文21个边沿/容器/树冠下垂状态。仍为透视与空间定义，生长时间、掉落产物和运行时生成尚未接入。
