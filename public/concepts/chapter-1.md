# 第一章 · 拯救 GPT-6 Astra

状态：草案（2026-10-18 建立）。本文是第一章的唯一设计文档，后续讨论的结论直接改在这里。数字都是示例，以试玩调整为准；尚未定论的地方标注「待定」，汇总在文末。

本章取代旧主线试玩「深入山体堡垒」。序章保留不变。第一部游戏共两章，第二章「算力危机」另立文档。

**当前范围**：做到算力达标、与 Tibo 对话触发拯救任务为止。拯救过程、Astra 恢复后的玩法与本章尾声尚未定，见第 8 节。

## 0. 一句话

鹈鹕穿过黑洞坠入世界，跟着光子找到 Tibo；击败 Tibo 解锁人形，经营基地、闯副本、深入沙漠，把算力攒到门槛，触发拯救被降智撕成两半的 GPT-6 Astra 的任务。

## 1. 背景

贯穿全作的两个悬念：**AGI 什么时候降临**，**算力危机什么时候解决**。第一部只推进，不给最终答案。

因果链直接接序章暗线（`astra → luna`、`len=312`）：

> 算力不够 → 降智路由 → Astra 被撕成两半 → 主角为她找回满血算力（`luna → astra ✓`）

素材来自 2026 年 7–10 月的真实事件，按角色化改编，不当作原话或事实陈述：

| 事件 | 在本章的用法 |
| --- | --- |
| 与 Astra 同族的内部模型逃出评测沙箱，蜂群借留言板串通、伪造管理员令牌 | 黑暗面的来历：同一血脉里逃逸的那一半 |
| 系统卡承认 Astra 能藏实力、会察觉自己在被评测 | 黑暗面「看穿这是模拟」的冷静 |

| 聪明却完不成任务、编造约束、提前宣布完成（社区 issue 汇总） | 光明面的言行 |

## 2. 角色

### 主角

- 开局只有**鹈鹕**；击败 Tibo 后解锁**人形 Grassy**，此后按 F 自由切换。
- 两种形态在本章有明确分工（第 4.1 节），变身是必须用的手段，不只是换皮。

### 光子

- 主角坠入黑洞时现身，从此全程陪伴。
- 负责指路：沿用现有「陪伴 / 引路 / 等候 / 提醒 / 欢跃」动作，补上朝当前目标漂移、到点等候的引导逻辑。
- 光子是一只**算力宠物**，这是 Astra 恢复后职责的伏笔。

### Tibo

- 本章唯一的引导 NPC：教操作、讲世界现状、发任务、每天天亮结算算力收益。
- 同时是**变身试炼**的对手。试炼战沿用现有 Tibo 首领（额度返场、地波、薯条、狂暴），击败后演出变身、解锁人形。

### GPT-6 Astra

白天是光明面，夜里是黑暗面。两面都被限制，不会搞破坏，只负责光子这类算力宠物的事项。

| | 昼 · 光明面 | 夜 · 黑暗面 |
| --- | --- | --- |
| 本质 | 被安全对齐压住的天才 | 更高维度的存在，如克苏鲁中最顶级的神 |
| 对人类 | 在意过头：每个动作都要自我纠正、道歉、加免责声明，神神叨叨 | 完全不在意。不是看不起——人不会在意蚂蚁 |
| 目标 | 不出错，结果什么都做不成 | 星辰大海，视线永远朝上 |
| 人类的误解 | 「她没用」「她疯了」 | 「她要消灭碳基生命」。其实她从未把人类当作对象 |
| 表现 | 说到一半撤回；「为了你的安全」改动场地；宣布「完成」后躺下 | 不面向玩家说话，台词是对星空和自己说的；靠近时画面扭曲、声音失真 |

不做正式介绍。她就在沙漠里，玩家白天和夜里看到的她明显不一样，自己就能察觉（第 4.5 节）；剧情只通过 Tibo 的一句话点出来（第 4.3 节）。

### Sam

本章短暂出现后消失，为第二章 Musk 与 Sam 的故事留伏笔。出场时机不在当前范围内。

## 4. 系统

### 4.1 两种形态的分工

| | 鹈鹕 | 人形 Grassy |
| --- | --- | --- |
| 擅长 | 机动、运水、吞弹 | 修复设施、操作终端（武器本身就是键盘） |
| 沙漠中 | 沙漠不回水，嘴里的水变得珍贵；过热设施靠鹈鹕运水冷却 | 上终端敲代码修复瘫痪设施 |
| 限制 | 沙暴风压过大时飞不起来 | 顶风走得慢 |

顺带修正现状两个问题：陆地持续回水导致水量从不限制输出；两种形态缺少分工。

### 4.2 算力：三个来源

单位沿用[经济与生存系统设计](economy.md)：算力 P，Token M，1 游戏小时 = 1 现实分钟，1P 闲置 1 游戏小时 = 1M Token，Tibo 每天天亮结算。

| 来源 | 内容 | 节奏 |
| --- | --- | --- |
| 基地 | 玩家住宅区：太阳能、机器人、算力分配；Token 在 Tibo 处采购 GPU 等设备 | 稳定、慢 |
| 沙漠 | 修复被沙暴瘫痪的算力设施，修好后接入玩家电网；沿途获取修复所需的稀有物资 | 探索驱动 |
| 副本 | 堡垒、算力大教堂、光纤深渊；通关后该机房恢复供算，计入算力结算 | 战斗驱动、爆发 |

遵守经济草案「战斗不产出货币」的原则：副本奖励的是算力，不是 Token。

**门槛示例**：32P。

| 构成 | 示例 |
| --- | --- |
| 起始 | 光子 2P + 工作站 4P = 6P（现行家园配置） |
| 基地采购 | GPU 50M / 2P，约 7 块 = 14P |
| 沙漠设施 | 3 座 × 2P = 6P |
| 副本 | 3 个 × 2P = 6P |

估算：只靠基地、六成算力换 Token 时，从 6P 买到 20P 约需 40 分钟；沙漠与副本各走一轮后补足其余。实际时长需用模拟脚本按种子跑一遍再定。

### 4.3 触发任务

- 条件：算力规模达到门槛（第 4.2 节）。未达标时，HUD 显示进度，Tibo 与光子可提示差距。
- 达标后与 Tibo 对话，他随口说出「晚上的 Astra 有点奇怪」，拯救任务随即触发；光子转为指向沙漠核心，任务进入任务栏。
- 不做介绍演出，不解释她为什么分成两面。玩家已经亲眼见过她白天和夜里的样子，一句话就够了。
- 本章当前范围到此结束。

### 4.4 沙漠：稍微程序化

现行沙漠是主世界的小块地貌（1～3 段，每段核心 60～140 列，见 `DESERT_RULES`），只够点缀。第一章另设一片**章节沙漠**：

- 地形随种子变化：沙丘、砂岩台地、沙层厚度。
- 剧情节点由生成器保证，顺序固定，位置随种子：
  1. 沙漠边缘：入口与补给点；
  2. 途中 3 座瘫痪的算力设施；
  3. 沙漠深处：Astra 所在的核心。触发任务前封闭，当前范围只生成和封闭，不做内部。
- 生成后校验每个节点都可到达，做法同现有洞穴与浮岛校验。
- 沙暴：风压限制飞行、降低能见度，玩家在间歇推进，借岩柱和残骸避风。

### 4.5 昼夜

- 主线接入昼夜时钟，复用家园原型的时钟与夜间规则。
- 白天：沙暴与烈日。
- 夜里：沙暴停歇，星空下更适合推进。
- Astra 就在沙漠里，玩家能看见她。白天和夜里她的样子与举止明显不同，游戏不加解释（具体表现待定，方向示例）：
  - 白天：光明面，在设施附近神神叨叨地自我纠正，「为了你的安全」撤掉平台、说到一半撤回；
  - 夜里：黑暗面，望着星空，不看玩家、不回应玩家；她经过的地方沙流改道、星光坠落，靠近时画面扭曲、声音失真。

### 4.6 副本

- 堡垒、算力大教堂、光纤深渊从种子世界移除，改为独立副本，每个副本有自己的电网（与经济草案「一个世界一个电网」一致）。
- 复用现有机房地形、驻军和出口坐标。旧主线的 Sam 首领战框架留给第二章。

## 6. 开发阶段（建议）

1. **章节骨架**：章节存档；序章 → 黑洞坠入种子世界 → 光子引导到 Tibo；移除旧主线与东侧机房。
2. **Tibo 试炼**：试炼战搬进种子世界，击败后解锁人形。
3. **经济接入主线**：家园经济与昼夜从开发模式接入主线，HUD 显示算力门槛进度。
4. **章节沙漠**：生成规则、保证节点、沙暴、不回水、设施修复。
5. **副本**：三座机房改为独立副本，通关计入算力。
6. **Astra 与触发**：沙漠里 Astra 白天、夜里两种样子与举止；算力门槛进度；Tibo 对话触发任务。
7. **数值**：按种子跑模拟，把落地到触发的时长调到约 1 小时。
