# 资源分类与命名

状态：已确认的基础标准。具体资源是否已经支持，以[材料与构件库](material-library.md)和实际游戏为准；设计图不代表所有组合已完成。

## 分类

| 类别 | 内容 | 编辑与行为边界 |
| --- | --- | --- |
| 建筑格子 | 天然土石、木料、岩板、合金、方石 | 材料和形状分别选择；可以铺地和盖房，不以摆放用途限制材料 |
| 背景墙 | 暖白岩板墙等 | 位于后侧墙层，不承托人物；与加深格互斥 |
| 建筑构件 | 平台、门、窗 | 每种构件使用统一规则，形状变化不另计为材料 |
| 摆放物件 | 家具、灯具、盆栽、功能设备 | 共同使用放置坐标与资源目录；具体承托、供能、照明行为由物件定义 |
| 建筑装饰 | 收边、包角、压条 | 记录依附与放置限制；没有实现的限制不得描述为已经生效 |
| 环境资源 | 城市、河流、无人机、远景植被 | 环境展示与玩家可建造物件分开登记，不因外观看起来像格子就成为可编辑区域 |

类别是资源定义，不要求界面增加多级菜单。

## 材料、类型、变化与系列

- 材料回答“表面和结构是什么”：暖白岩板、深蓝合金、米黄色方石。
- 构件类型回答“它是什么、如何工作”：块、墙、平台、窗、能量门。
- 变化是同一资源的形状或放置属性：全砖、上下半砖、四分之一块、左右半宽、加深、顶齐方式。
- 系列表示外观协调的物件组合，例如蓝白合金家具；以后红木家具沿用对应家具的尺寸和行为标准。
- 具体资源必须有名称，例如深蓝合金能量门，不能只用“门”“科技物件”代替。

## 正式命名

| 对象 | 名称 |
| --- | --- |
| 白色建筑格子 | 暖白岩板块 |
| 白色背景墙 | 暖白岩板墙 |
| 白色平台 | 暖白岩板平台 |
| 蓝色建筑格子 | 深蓝合金块 |
| 蓝色平台 | 深蓝合金平台 |
| 蓝色金属窗框 | 深蓝合金窗 |
| 蓝色金属门框与能量屏障 | 深蓝合金能量门 |
| 米黄色建筑石材 | 米黄色方石块 |
| 当前家具系列 | 蓝白合金家具 |

“暖白岩板块”是岩板饰面的建筑模块，玩家直接作为格子建造，不需要再叠一层饰面。岩板、合金、方石是本游戏选定的材料设定，不是对参考原画真实制造材料的鉴定。旧存档中的内部标识不随中文名称改变，例如 ceramic 继续标识暖白岩板，避免更名破坏存档。

同一系列可以同时包含金属框架、岩板台面和织物软垫；不能把床垫和椅垫都称作岩板。

## 格子与平台的变化

普通建筑格前后深度为 2 格。加深是在基础格上前后各增加 0.5 格，总深度 3 格；不是另一个材料。

一个 1×1 格内可以组合互不重叠的形状。四个小块是四个 0.5×0.5 象限，合起来面积为一个整格；上下半砖各高 0.5、宽 1，不能把它们与四个小块混称。放置、选中、替换、拆除按实际块处理。

任一小块使用加深规格时，该父格内不能放背景墙；已有背景墙也禁止放入加深小块。互斥按整个父格检查，不按小块剩余空隙检查。

米黄色方石的相邻两格可以视觉合缝，但逻辑上仍是两格。只有同材、同形、同高度、同深度且位于同一固定配对的两块合并外观；单块、断开和混材处保留边缘。合缝不得妨碍逐格编辑。

平台仍然是平台：整宽、左半、右半属于宽度变化；居中与挂墙由背景墙决定；整砖顶齐和半砖顶齐是安装高度。平台承托顶面必须与渲染顶面一致，不另外登记“平台变体材料”。完整尺寸见[平台定义](platform-definitions.md)。

## 资料库字段

每个资源记录正式名称、类别、材料或系列、占格宽高、前后深度、形状、安装条件、碰撞与承托、拼接、建造与拆除权限、实现状态，以及共享游戏预览入口。

状态用“已确认规则”“待实现”“已实现待验收”“已验证”区分。目录展示、自由搭建和游戏场景必须共用资源配置与生成器，不能各自复制一套尺寸或模型。

## 材质表现

暖白岩板采用细微、稳定的色差与表面颗粒，避免夸张的大理石纹；米黄色方石保留石材差异，深蓝合金使用金属表面。变化依物件位置确定，不能每次重建随机变化。倒角高光、反光和投影应随太阳、天气和灯光变化，不把固定方向的阴影画死在纹理里。
