# 树木：各阶段独立定义与透视图

状态：2026-10-10 设计资料。本文可独立复制；所有新增数字均为**绘图草案**，不代表游戏模型、生长、碰撞、采集或存档已经按此实现。

## 已有依据与本次草案

既有经济设计明确树木会自然重新生长。树高、树冠、干径、各阶段尺寸和树桩萌发方式均是本次绘图草案；自然再生的既有方向不等于已确定采用树桩再萌，更不代表以下阶段已接入游戏。

树根周围只留0.6×0.5根口，余下宿主顶面继续铺草；幼苗、成树、砍后树桩保持同一落点。砍树不移除周围草。图示树心距4格、冠宽各3格，冠间余1格；冠后沿+0.4与后墙+0.5相隔0.1。前叶遮住角色时局部淡化前叶，树干、后叶和树冠轮廓保留。坡面树干保持竖直、根口真实承托；宿主挖空后不留下悬空树。这些均为本轮透视表现方案。

## 树干、树冠与高度

根颈锚点为 (0,0,−0.3)，Y=0 为实际土壤顶面。全株宽深是含树冠的最大外观包络，全株总高量到最高叶片；树干高度量到主干上端，树冠可包覆树干上部，不能把树干高与全株高相加。

| 状态 | 主茎/树干宽 | 主茎/树干高 | 说明 |
| --- | --- | --- | --- |
| 幼苗 | 0.06 | 0.35 | 细茎，叶片最高到 Y=0.6 |
| 幼树 | 0.12 | 1.2 | 全株最高到 Y=2 |
| 生长中 | 0.25 | 2.2 | 全株最高到 Y=3.5 |
| 成熟成树 | 0.4 | 3.3 | 全株最高到 Y=5 |
| 砍伐后树桩 | 0.4 | 0.3 | 树桩宽深均为 0.4 |
| 树桩再萌 | 0.4（原桩） | 0.3（原桩） | 新芽另从树桩附近长出，最高到 Y=0.8 |

成熟预留宽 3×高 5×深 1.4，范围 X=[−1.5,+1.5]、Y=[0,5]、Z=[−1,+0.4]。树冠可以伸入内沿区，根与树干底部仍需真实土壤承托。成熟树干宽 0.4 不等于整片宽 3 的冠层都是障碍物。

## 生长、砍伐与再生

- 生长草案：幼苗 → 幼树 → 生长中 → 成熟成树。
- 砍伐：成熟成树 → 砍伐后树桩，树冠和高干移除，仅保留低桩；木材产出量、采伐次数及树倒动画未定。
- 候选再生图：树桩 → 树桩再萌 → 后续生长；这张图展示一种可讨论的外观，不将它定为唯一再生算法。
- 另一种可能是重新生成幼苗；采用哪一种、何时触发、是否受空间和土壤限制均待定，不能同时宣称两种都已经实现。
- 若未来允许拔桩或连根移除，原实例成为零实体，与“砍伐后保留树桩”不同；再造林或自然生成需另定。

## 碰撞与待定项

树干是否阻挡、阻挡的宽高、砍伐选取范围待定；根部宿主1格、局部根口0.6×0.5已在上图定义。普通树冠不自动承托角色；若某些枝干可站立，需单独定义平台，不能用全树包络生成平台。

成熟预留用于建筑净空检查，幼树当前只高 2 格不意味着只需预留 2 格。生长与新建筑冲突时暂停生长是候选规则；宿主被挖空后移除对应树，掉落和倒伏动画另定。若进入玩法，生长阶段、采伐进度与再生状态应保存，读档不能还原已砍树。
