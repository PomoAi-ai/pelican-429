# 核心术语

状态：基础术语（2026-10-16 更新建筑材料、形态与摆放物件）。本页是全部概念资料的统一术语表。资料中只使用“正式名”；“停用叫法”出现在旧资料里时，按本页对应的正式名理解，并在改写时替换。坐标与单位见 [core-coordinates.md](core-coordinates.md)。

“代码标识”只记录对应关系，不要求改代码。
